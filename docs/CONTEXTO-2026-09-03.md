## P1 — Firma de webhooks · CERRADO

**Causa raíz:** la cuenta de Retell tenía **dos API keys**:

| Nombre | Badge | Termina en | Uso |
|---|---|---|---|
| `casamable-outbound` | — | `0346` | la que estaba en el `.env` |
| `Secret Key` | **Webhook** | `6ceb` | la que Retell usa para FIRMAR |

`verifyWebhook` usaba `RETELL_API_KEY` (`...0346`). Retell firmaba con `...6ceb`. El HMAC no podía coincidir jamás.

**Por qué costó encontrarlo:** el algoritmo, el formato del header, el reloj, el Basic Auth y la alcanzabilidad eran todos correctos. Una petición firmada por nosotros con la key configurada **pasaba** — porque usábamos la misma clave equivocada a ambos lados.

**Arreglo (commit `183617f`):** verificación extraída a `src/lib/calls/retell-webhook.ts`, alineada línea a línea con el SDK oficial (`retell-sdk@5.64.0`), con un test que fija un vector generado por el propio SDK. Más rotación de `RETELL_API_KEY` a la key badged.

**Evidencia de cierre:** llamada entrante real 21:07 → `call_started`, `call_ended`, `call_analyzed` aceptados, **0 `call_webhook_bad_signature`**. El sistema registró la verificación en `settings` con fecha.

## Aprendizajes operativos del NAS

- `alpine/git` deja permisos que rompen el build: **`chmod -R a+rX <repo>` es obligatorio** tras clonar o hacer fetch.
- `git clean -fd` borra los `.env.bak-*` (no están en `.gitignore`). Guardar copias del `.env` **fuera** del repo.
- Escribir en volúmenes montados requiere `--user 0:0` (ACLs del NAS).
- El contenedor no trae `sqlite3` ni `npm` en el host: usar `alpine:3.19` con el volumen montado, o `docker exec`.
- Los logs de Next.js en producción **no registran peticiones HTTP**: para saber si un webhook llegó, mirar `integration_events`.
- Editar el prompt de Retell desde la UI es frágil (una línea en blanco rompió la comparación byte a byte). **Escribirlo por API** con `PATCH update-retell-llm` es determinista.
- En Retell, "V19 ACTIVA" en el dashboard **no significa publicada**: hay que comprobarlo por API (`get-agent?version=19` → `is_published`).
