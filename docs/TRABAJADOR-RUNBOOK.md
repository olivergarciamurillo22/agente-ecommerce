# Tu espacio de atención al cliente

Entra en `/login` con tu correo y contraseña. Tu única zona de trabajo es `/trabajo`.

La bandeja muestra primero a quien más tiempo lleva esperando. Abre una conversación para leer el hilo completo y la ficha del pedido. Verás solo los datos necesarios para ayudar al cliente.

Pulsa **Atender** antes de responder: así el bot se calla. Cuando hayas terminado, puedes pulsar **Devolver al bot**. Puedes guardar una dirección corregida, una nota para el repartidor y reenviar una confirmación una vez por pedido y día. Para cerrar un caso, usa **Marcar resuelto** y explica brevemente qué hiciste.

Si la pantalla dice que la ventana de 24 horas está cerrada, no podrás escribir un mensaje normal. Usa **Escalar a Pedro**. Escala también cuando el cliente pide cancelar, el pedido no encaja con la ficha, faltan datos, hay dudas sobre un cobro o no sabes con seguridad qué hacer.

No canceles pedidos ni prometas cambios en Shopify, llamadas o fechas que no aparecen confirmadas. Pedro decide esas acciones. Todo cambio queda registrado con tu nombre y hora para que el equipo pueda reconstruir lo ocurrido.
